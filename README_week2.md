# WeIntern Data Science — Week 2

**Author:** Sankalp Padhi  
**Dataset:** Synthetic e-commerce sales dataset with intentional data-quality issues.

## Tasks
1. Data cleaning and preprocessing.
2. Exploratory data analysis (EDA) with multiple visualizations.
3. Sales prediction using Linear Regression and Random Forest.

## Files
- `data/raw/week2_raw_ecommerce_sales.csv` — original messy dataset; do not overwrite.
- `data/cleaned/` — cleaned CSV generated by the notebook.
- `notebooks/week2_data_science_assignment.ipynb` — end-to-end workflow.
- `outputs/charts/` — charts generated by notebook execution.
- `reports/` — KPI, quality-comparison, and model-comparison CSVs.

## Run
From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook
```

Open `notebooks/week2_data_science_assignment.ipynb` and run cells from top to bottom.

## Notes
The raw dataset is deliberately messy for learning purposes. Cleaning decisions are documented in the notebook. Model results are illustrative only because the dataset is synthetic and small.
